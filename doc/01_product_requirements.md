# 轻琴 (PianoEase) iPad App — 产品需求文档

> **版本**：v1.0
> **日期**：2026-07-13
> **状态**：已确认
> **阶段**：Phase 1.5 — iPad 原生练琴版
> **前置文档**：PianoEaseWeb/doc/01~08

---

## 一、产品目标

### 1.1 核心命题

> **在 iPad 上复现 Web 版已验证的练琴体验，解决 iPad Safari 不支持 Web MIDI 的问题。**

Phase 1（Web MVP）已验证：「左手简化曲谱」能让初学者弹完一整首歌。  
Phase 1.5 的目标是把这个体验落到 iPad 原生 App，因为 iPad 是用户最自然的练琴终端。

### 1.2 产品定位

- **不是**重做一套新产品
- **而是**将 Web 版核心体验移植到 iPad，补齐 MIDI 能力
- 一期先做本地离线版，二期对接 Web API 数据打通

### 1.3 成功标准

| 指标 | 目标值 | 含义 |
|---|---|---|
| iPad MIDI 连接成功率 | > 95% | USB/蓝牙 MIDI 键盘能稳定连接 |
| 练习流程完成率 | > 80% | 用户从选曲到看报告的完整流程 |
| 瀑布流渲染帧率 | ≥ 60fps | 练习体验流畅无卡顿 |
| MIDI 输入延迟 | < 20ms | 弹奏反馈实时 |

## 二、用户故事

### 2.1 主线流程

```
用户打开 App → 浏览曲库 → 选一首歌 → 选难度(Lv1/Lv2/Lv3) → 查看简谱预览
    → 连接 MIDI 键盘 → 进入瀑布流练习（等待模式）→ 弹奏 → 看评分报告
    → 再练一次 / 换难度 / 回首页
```

### 2.2 详细用户故事

| # | 用户故事 | 优先级 |
|---|---|---|
| US-1 | 作为用户，我打开 App 就能看到所有可练习的曲目列表 | P0 |
| US-2 | 作为用户，我能通过曲名搜索找到想练的歌 | P1 |
| US-3 | 作为用户，我能看到每首歌的难度、BPM、时长信息 | P0 |
| US-4 | 作为用户，我能选择 Lv1/Lv2/Lv3 不同难度的简化版 | P0 |
| US-5 | 作为用户，我能在简谱预览中看到当前难度的前几小节 | P1 |
| US-6 | 作为用户，我能连接 USB 或蓝牙 MIDI 键盘 | P0 |
| US-7 | 作为用户，我能看到 MIDI 键盘的连接状态 | P0 |
| US-8 | 作为用户，我能在瀑布流模式下练习（等待模式） | P0 |
| US-9 | 作为用户，弹对的音符会有 Perfect/Good 视觉反馈 | P0 |
| US-10 | 作为用户，练习结束后能看到评分报告 | P0 |
| US-11 | 作为用户，我能查看历史练习记录 | P1 |

## 四、页面与交互设计

### 4.1 页面结构

```
┌─────────────────────────────────────────────────────┐
│  PianoEase iPad App                                  │
├─────────────────────────────────────────────────────┤
│                                                      │
│  P1. 首页（曲库列表）                                  │
│     ├── P2. 曲目详情 / 练习准备页                      │
│     │     └── P3. 瀑布流练习页                         │
│     │           └── P4. 练习报告页                     │
│     └── P5. 练习历史页                                │
│                                                      │
│  全局：MIDI 连接状态指示 + 设备管理弹窗               │
│                                                      │
└─────────────────────────────────────────────────────┘
```

### 4.2 P1 — 首页（曲库列表）

**布局**：iPad 横屏，3 列卡片网格

**每张卡片信息**：
- 曲名（中文）+ 英文/副标题
- 难度标签（入门=绿色 / 进阶=橙色 / 挑战=红色）
- BPM + 时长
- 操作按钮：「开始练习」「查看曲谱」

**交互**：
- 点击卡片 → 进入 P2 曲目详情页
- 顶部搜索栏
- 右上角 MIDI 状态指示灯（🟢/🔴，点击弹出设备管理）

### 4.3 P2 — 曲目详情 / 练习准备页

**核心选择项**：

| 选项 | 可选值 | 默认值 |
|---|---|---|
| 左手难度 | Lv1 根音 / Lv2 柱式和弦 / Lv3 分解和弦 | Lv1 |
| 速度 | 50% / 75% / 100% | 100%（一期预留，暂不实现） |

**预览区**：显示当前难度下的简谱（前 4-8 小节）

**底部**：大按钮 **[开始练习]**

### 4.4 P3 — 瀑布流练习页

**布局**（iPad 横屏）：

```
┌──────────────────────────────────────────┐
│  曲名      Lv1 根音    00:32/02:15  ⏸ ✕ │ ← 顶栏
├──────────────────────────────────────────┤
│                                          │
│    ██                                    │
│       ██  ██                             │ ← 音符块下落区
│          ██     ██                       │   左手蓝色 / 右手绿色
│    ██        ██    ██                    │
│                                          │
│══════════════════════════════════════════│ ← 判定线
│  ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃  │ ← 虚拟琴键
├──────────────────────────────────────────┤
│  Score: 860    Combo: 12    ⭐⭐⭐        │ ← 底栏
└──────────────────────────────────────────┘
```

**等待模式行为**：
- 音符下落到判定线后暂停
- 用户在 MIDI 键盘上弹对正确音符后，自动前进到下一个
- 弹错显示红色闪烁反馈
- 适合初学者逐音拆谱

**判定规则**（与 Web 版一致）：
- Perfect：±50ms → +100 分
- Good：±150ms → +50 分
- Miss：超出窗口 → 0 分，Combo 断裂

### 4.5 P4 — 练习报告页

**练习结束后自动弹出**：

| 区域 | 内容 |
|---|---|
| 总分/星级 | ⭐⭐⭐ 860 分 |
| 准确率 | 右手 92% / 左手 78% |
| 节奏评价 | 整体偏快 3ms / 节奏稳定 |
| 错音热力图 | 按小节色块深浅 |
| 薄弱小节 | 第 8 小节 |
| 操作按钮 | [再练一次] [换难度] [回首页] |

### 4.6 P5 — 练习历史页

- 按时间倒序列表
- 每条记录：曲名 + 难度 + 分数 + 准确率 + 日期
- 点击可查看该次练习的详细报告
